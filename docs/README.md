# Younus Koronfel — Portfolio

Open `../index.html` or serve the repository root using a static HTTP server. The three source files are `index.html`, `style.css`, and `script.js`. There is no build step or distribution folder.

The portfolio uses a centered blue-and-neutral theme, an experience timeline, filterable project cards, education and leadership sections, a toolbox, an embedded résumé, and an email-draft contact form. The layout follows the supplied visual reference while the content describes Younus Koronfel.

Appearance controls provide System, Light, Dark, and Midnight modes, brightness from 60% to 120%, and reduced motion. Preferences are saved in local browser storage when available; the System mode follows the device color scheme.

The supplied portrait and a rendered preview of the original résumé are in `images/`. The accessible original PDF is in `docs/`, with an interactive PDF viewer, direct-open link, and download link. Refresh `images/resume-preview.png` from the PDF if the résumé changes.

The contact form opens the visitor’s email application with a prepared message. It does not send automatically or require a backend. Project visuals are conceptual, and all project claims are based on the supplied résumé.

The previous private hosted site is a separate publication. These local changes do not update GitHub or the hosted site until explicitly pushed or published.

Each project card contains a live interactive demonstration, visible and usable immediately on page load. The database demo traces a pizza order through menu, recipe, and inventory records, with quantity scaling. The profitability demo models orders, ingredient costs, and waste, with a reset and disclosed assumptions. The sales dashboard switches between revenue and order counts and filters the sample date range. All three use fictional data and run inside the portfolio without external services.
