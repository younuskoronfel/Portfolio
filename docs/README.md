# Younus Koronfel — Portfolio

Open `../index.html` directly, or serve the repository root with any static web server.

The website has exactly three source files in the root: `index.html`, `style.css`, and `script.js`. The photo is in `images/`; the original résumé PDF is in `docs/`. Edit these files directly. No build step, generated folder, or dependencies are required.

The résumé is embedded in the page, with download and open-in-new-tab links for browsers that do not support inline PDFs. The project demonstrations use explicitly illustrative data.

The previous private Sites deployment has project ID `appgprj_6ade24ae48b88191bf3e98903fc775e5`. Its old dist-based hosting configuration has been removed from this source tree. This restructuring is local and does not change the deployed site until a separate publication is requested.
