## Add a Featured link

On desktop, open your LinkedIn profile. Select **Add profile section → Recommended → Add Featured** if the section is missing. In Featured, select **+ → Add a link**, paste the portfolio URL, and follow the prompts to save it. If Featured already exists, start with its + button. On mobile, open your profile and use **Add section → Recommended → Add featured**, or the + button in the existing section.

## Add your website to Contact info

On desktop: **Me → View Profile → Contact info → pencil icon → Add website**. Enter the portfolio URL, choose the closest website type (Portfolio if offered), and Save.

On mobile: open your profile, tap the introduction pencil, then **Edit contact info → Add website**. Paste the URL, select a type, and Save.
